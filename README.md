# ThunderBolt — Total Assistance for Visually Impaired People

PathGuide: a camera + Claude vision navigation assistant for blind users, demoed on a cap-mounted Android phone.

- `index.html` / `pathguide.html` — the complete single-file app (all CSS/JS inline, no build step).
- Deployed on Netlify; requires HTTPS for camera access (Netlify provides this).
